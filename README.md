Node_modules er fjernet, i versionen der er uploadet til canvas, så husk at geninstaller den hvis man er kommet derfra.

Link til video gennemgang af appen i Loom:
https://www.loom.com/share/c80246ecd6244ddfa1c7fbe6e177ccba

For at starte applikationen gennem Expo Go, skal man gøre følgende: 

Naviger frem til den rette fil:
cd '.\Obliga 1\' 

Således at ens path ser sådan her ud:
..\INNT Obligatorisk opgave 1\Obliga 1>

Derefter start expo tunnel:
npx expo start --tunnel

I tilfælde af problemer kan man eventuelt kører den her i stedet:
npx expo start -c --tunnel
